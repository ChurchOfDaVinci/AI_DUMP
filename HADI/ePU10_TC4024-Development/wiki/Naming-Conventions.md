# Naming Conventions: Prefix

For declaring variables use a prefix to indicate the type of variable:

| Type | Prefix |
|------|--------|
| `REAL` | `r_` |
| `LREAL` | `lr_` |
| `BYTE` | `by_` |
| `BOOL` | `b_` |
| `WORD` | `w_` |
| `DWORD` | `dw_` |
| `UINT` | `ui_` |
| `INT` | `i_` |
| `USINT` | `usi_` |
| `STRING` | `s_` |
| `Enums` | `e_` |
